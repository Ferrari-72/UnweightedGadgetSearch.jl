# Abbreviations Quick Reference

A quick lookup table for common abbreviations in computation theory.

---

## Complexity Classes

| Abbr. | Full Name | What It Means |
|-------|-----------|---------------|
| **P** | Polynomial Time | Problems solvable quickly by classical computers |
| **NP** | Nondeterministic Polynomial Time | Problems where solutions can be verified quickly |
| **NP-hard** | NP-hard | At least as hard as the hardest problems in NP |
| **NP-complete** | NP-complete | Both in NP and NP-hard (the "hardest" NP problems) |
| **BQP** | Bounded-error Quantum Polynomial Time | Problems solvable quickly by quantum computers |
| **QMA** | Quantum Merlin-Arthur | Quantum version of NP |
| **PSPACE** | Polynomial Space | Problems solvable with polynomial memory |
| **EXPTIME** | Exponential Time | Problems requiring exponential time |

---

## Problem Names

| Abbr. | Full Name | What It Is |
|-------|-----------|------------|
| **SAT** | Boolean Satisfiability | Can we make a Boolean formula TRUE? |
| **3-SAT** | 3-Satisfiability | SAT where each clause has exactly 3 variables |
| **CNF** | Conjunctive Normal Form | Standard format: (clause₁) AND (clause₂) AND ... |
| **TSP** | Traveling Salesman Problem | Find shortest route visiting all cities |
| **MIS** | Maximum Independent Set | Find largest set of unconnected vertices |

---

## Computation Basics

| Abbr. | Full Name | What It Means |
|-------|-----------|---------------|
| **TM** | Turing Machine | Abstract model of a computer |
| **UTM** | Universal Turing Machine | A TM that can simulate any other TM |
| **DTM** | Deterministic Turing Machine | TM with one possible action per state |
| **NTM** | Nondeterministic Turing Machine | TM that can "try all paths at once" |

---

## Quantum Computing

| Abbr. | Full Name | What It Means |
|-------|-----------|---------------|
| **Qubit** | Quantum Bit | Basic unit of quantum information (can be 0 AND 1) |
| **CNOT** | Controlled-NOT | Two-qubit quantum gate |
| **H** | Hadamard Gate | Creates superposition from |0⟩ or |1⟩ |
| **QFT** | Quantum Fourier Transform | Quantum version of Fourier transform |

---

## Notation

| Symbol | Meaning |
|--------|---------|
| **O(n)** | Big-O notation: grows like n |
| **O(n²)** | Grows like n squared |
| **O(2ⁿ)** | Grows exponentially (very slow!) |
| **≤ₚ** | Polynomial-time reduces to |
| **∈** | "is in" or "belongs to" |
| **⊆** | "is a subset of" |

---

## Quick Memory Tips

- **P** = "**P**olynomial" = Fast ✓
- **NP** = "**N**ot necessarily **P**olynomial" = Maybe slow, but easy to check
- **BQP** = "**B**ounded **Q**uantum **P**olynomial" = Fast for quantum
- **SAT** = "**SAT**isfy the formula?"
