## 🎯 核心概念

### 什么是 Gadget？

**Gadget（组件）** 是图转换的**基本构建模块**，每个 gadget：
1. 有一个**模式**（pattern）- 要被替换的部分
2. 有一个**替换**（replacement）- 替换后的部分
3. **保持 MIS 等价性**（α-tensor 相差常数）
4. **可以嵌入** King's 图

**类比**：就像乐高积木，每块积木（gadget）可以替换图中的特定结构。

---

## 🔄 Gadget 的旋转和反射

### 为什么需要变换？

**问题**：同一个 gadget 在图中可能出现在**不同方向**。

**例子**：
```
图中有转弯，但方向不同：
    ↓
    ●───●     ← 向右转
    │
    ●

    ●
    │
    ●───●     ← 向左转（需要旋转版本）
    ↑
```

### 旋转（Rotation）

**意思**：把 gadget **转个方向**（90°, 180°, 270°）。

**为什么可以旋转？**
- 旋转只是**几何变换**，不改变：
  - ✅ 图的结构（哪些点相连）
  - ✅ α-tensor（边界状态 → 能选几个点）
  - ✅ MIS 等价性

**例子**：
```
原始 Turn（向右）：
⋅ ● ⋅ ⋅
⋅ ● ⋅ ⋅
⋅ ● ● ●

旋转 90°（向下）：
⋅ ⋅ ⋅ ⋅
⋅ ● ● ●
⋅ ⋅ ⋅ ●
```

### 反射（Reflection）

**意思**：把 gadget **镜像翻转**（沿 x 轴、y 轴、对角线等）。

**为什么可以反射？**
- 同样只是几何变换，不改变本质属性。

### 为什么要提前生成所有变体？

**如果实时计算**：
```
匹配时：
1. 看到模式
2. 尝试原始 gadget → 不匹配
3. 计算旋转 90° → 不匹配
4. 计算旋转 180° → 匹配！✓
```
每次都要计算，**慢**！

**提前生成**：
```
匹配时：
1. 看到模式
2. 直接查表：原始、旋转90°、旋转180°、旋转270°、反射x、反射y...
3. 找到匹配的 ✓
```
直接查表，**快**！

**一句话总结**：
> Gadget 可以旋转/反射，因为只是改变方向，不改变本质（α-tensor）。提前生成所有变体是为了匹配时效率更高。

## 🧰 crossing_ruleset（交叉规则集）

### 这是什么？

**crossing_ruleset** 是算法的**"工具箱"**，装着所有可用的 gadget。

**包含什么？**

1. **基础组件**（原始版本）：
   - `Cross{false}()` - 主要交叉组件（BATOIDEA）
   - `Turn()` - 转弯组件
   - `Branch()` - 分支组件
   - `TCon()` - T 型连接
   - 等等...

2. **变换版本**（旋转/反射）：
   - `RotatedGadget(TCon(), 1)` - TCon 旋转 90°
   - `ReflectedGadget(Cross{true}(), "y")` - Cross 沿 y 轴反射
   - `ReflectedGadget(RotatedGadget(TCon(), 1), "y")` - 组合变换（先旋转再反射）

### 怎么用？

**算法流程**：
```
1. 看到图中有个"交叉"模式
   │
   ▼
2. 遍历 crossing_ruleset 里的所有 gadget
   - 试试 Cross{false}() → 匹配吗？
   - 试试 RotatedGadget(...) → 匹配吗？
   - 试试 ReflectedGadget(...) → 匹配吗？
   │
   ▼
3. 找到第一个匹配的 → 应用它！
   │
   ▼
4. 继续找下一个模式...
```

**一句话总结**：
> crossing_ruleset 是算法的"工具箱"，装着所有可用的 gadget（包括旋转、反射版本），算法转换图时从这个工具箱里找合适的 gadget 来替换复杂模式。

## 📋 主要 Gadget 类型

### 1. Copy Gadget（复制组件）

**作用**：在网格上"复制"一个顶点的值，形成 T 形结构。

**为什么 T 形？**
- 垂直部分：连接上下其他顶点
- 水平部分：允许边交叉

### 2. Crossing Gadget（交叉组件）- BATOIDEA

**作用**：处理边的交叉（原图不能直接在 King's 图上表示交叉）。

**特点**：
- 11 个顶点
- 通过计算机搜索找到
- 可以嵌入方形网格

### 3. Turn Gadget（转弯组件）

**作用**：改变 copy line 的方向（90°转弯）。

### 4. Branch Gadget（分支组件）

**作用**：一个 copy line 分成多个分支（用于度数 > 2 的顶点）。

## 🔍 计算机搜索如何找到 Gadget？

### 搜索算法（Algorithm C.1）

```
For 每个图大小 n（从小到大）:
    For 每个非同构图 G（n 个顶点）:
        For 每个边界顶点选择:
            R' = (G, 边界)
            
            If 通过过滤规则:
                计算 α̃(R')
                If α̃(R') 与 α̃(CROSS) 相差常数:
                    If 可以嵌入 unit disk graph:
                        找到了！返回 R'
```

### 过滤规则（优化）

1. **边界连接**：边界 (1,3) 或 (2,4) 不能直接相连
2. **对称性**：利用问题对称性避免重复搜索
3. **交叉条件**：路径必须几何上交叉

### 搜索结果

- 搜索了 ≤11 个顶点的图
- 找到了 **4 个**有效的替换图
- 其中 **BATOIDEA** 可以嵌入方形网格

## ✅ 关键理解总结

| 概念 | 我的理解 |
|------|----------|
| Gadget | 图转换的基本构建模块，可以替换图中的特定结构 |
| 旋转/反射 | 只是改变方向，不改变本质（α-tensor），所以可以提前生成 |
| crossing_ruleset | 算法的"工具箱"，装着所有可用的 gadget 及其变体 |
| 为什么提前生成 | 提高匹配效率（查表 vs 实时计算） |
